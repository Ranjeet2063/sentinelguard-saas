# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

SentinelGuard is an automated security scanner protecting codebases from secret leaks and invariant violations.

If you discover a vulnerability in the webhook verification, billing engine, or scanner daemon:

1. **Do NOT open a public issue.**
2. Email **`guptakumarranjeet150@gmail.com`** with:
   - Reproduction steps or payload.
   - Component affected (`src/server.ts`, webhook handlers, or scan engines).
3. We will respond within 24 hours and deploy an authorized patch with high priority.
